AURA settings

AURA talks to the AURA service, or to an AURA server you run on this computer — nothing else. Your AI provider API key is held by this extension and is sent only to that provider: the AURA service never receives it. Set the provider and key in the panel’s AI provider section.

With the AURA service this is issued automatically on first use and there is nothing to paste. Running your own server? Start it with python -m aura.api, which prints a token, and paste it here. The token only authorises this extension to use that server.
